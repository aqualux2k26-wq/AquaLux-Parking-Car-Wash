# Search Engine Optimization (SEO) Strategy

## SEO Highlights for aqualuxparkingcarwash.com

### 1. Structured Data (JSON-LD)
`index.html` and `src/config/seo.ts` include Schema.org `AutoWash` structured data providing Google and search crawlers with:
- Business Name: **AquaLux Parking Car Wash**
- Canonical Domain: `https://aqualuxparkingcarwash.com`
- Telephone & Contact Details
- Price Range (`$$`)
- Offer Catalog: Parking Car Wash, Parking Management, Car Wash Stations, Valet Parking

### 2. Meta Tags & OpenGraph
- Pre-configured OpenGraph Facebook tags (`og:title`, `og:description`, `og:image`, `og:url`)
- Twitter Large Card meta tags (`twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`)
- Canonical URL targeting `https://aqualuxparkingcarwash.com/`

### 3. Core Search Engine Files
- `public/robots.txt`: Directs search engine bots and points to the sitemap location.
- `public/sitemap.xml`: XML sitemap with all section anchor links and update priorities.
- `public/manifest.json`: Web App Manifest for mobile indexing and home-screen bookmarking.

### 4. Image Alt Tag Compliance
All SVG and graphic assets include descriptive `alt` tags and `referrerPolicy="no-referrer"` attributes to maximize image search visibility.
